# Benchmarking

Measuring execution time of C programs to compare implementations
and reason about efficiency and energy use.

| File | Description |
|---|---|
| `baseline_loop-metrics.md` | Output of three consecutive runs of `baseline_loop` |
| `comparison_algorithms-metrics.md` | Timing comparison of a naive O(n^2) and a single-pass O(n) algorithm |
| `green_efficiency_analysis.md` | Written report on measurements, runtime and energy |
