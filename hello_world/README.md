# Hello, World

Introduction to C: compilation steps, gcc, printing, and Betty style.

| File | Description |
|---|---|
| `0-preprocessor` | Runs a C file through the preprocessor and saves the result in `c` |
| 1-compiler | Compiles a C file without linking and outputs a .o file |
| 2-assembler | Generates the assembly code of a C file into a .s file |
| 3-name | Compiles a C file and creates an executable named cisfun |
