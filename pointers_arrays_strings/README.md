# C - Pointers, arrays and strings

| File | Description |
|---|---|
| `main.h` | Header file with all function prototypes |
| `0-reset_to_98.c` | Function that updates the value an int pointer points to, to 98 |
| `1-swap.c` | Function that swaps the values of two integers |
| `2-strlen.c` | Function that returns the length of a string |
| `3-puts.c` | Function that prints a string followed by a new line |
| `4-print_rev.c` | Function that prints a string in reverse |
| `5-rev_string.c` | Function that reverses a string in place |
