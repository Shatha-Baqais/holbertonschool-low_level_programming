# C - Pointers, arrays and strings

| File | Description |
|---|---|
| `main.h` | Header file with all function prototypes |
| `0-reset_to_98.c` | Function that updates the value an int pointer points to, to 98 |
| `1-swap.c` | Function that swaps the values of two integers |
| `2-strlen.c` | Function that returns the length of a string |
| `3-puts.c` | Function that prints a string followed by a new line |

| `5-rev_string.c` | Function that reverses a string in place |
| `6-puts2.c` | Function that prints every other character of a string |
| `7-puts_half.c` | Function that prints the second half of a string |
| `9-strcpy.c` | Function that copies a string, including the null byte |
| `100-atoi.c` | Function that converts a string to an integer |
| `0-strcat.c` | Function that concatenates two strings |
| `1-strncat.c` | Function that concatenates at most n bytes of src to dest |
| `2-strncpy.c` | Function that copies at most n bytes of a string, like strncpy |
| `3-strcmp.c` | Function that compares two strings |
