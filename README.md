# holbertonschool-low_level_programming

Holberton School low-level programming projects in C.

## Projects

| Folder | Topic |
|---|---|
| hello_world | First C programs and compiling with gcc |
| variables_if_else_while | Variables, conditions and loops |
| functions_nested_loops | Functions and nested loops |
| more_functions_nested_loops | More practice with functions and loops |
| pointers_arrays_strings | Pointers, arrays and strings |
| intro_debugging | Finding and fixing bugs |
| malloc_free | Dynamic memory with malloc and free |
| more_malloc_free | More dynamic memory practice |
| structures_typedef | Structures and typedef |
| simple-calculator | A simple calculator in C |
| benchmarking | Measuring program performance (instrumentation_lab.c times each phase with clock()) |

## Requirements
- Ubuntu 20.04
- gcc with `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty coding style
